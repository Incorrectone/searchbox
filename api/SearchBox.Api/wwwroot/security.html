SearchBox Security dashboard

🛡 What you're looking atnear-real-time (≤ 1 h)

Every request that reaches this site, from people and bots alike, is logged at the edge and analysed in BigQuery. Pages sit behind a proof-of-work challenge (Anubis); requests for things like /.env or /wp-login.php are denied and counted as exploit probes.

IP addresses are masked to their network (IPv4 /24, IPv6 /48) and the owner's own networks are excluded. Country, network owner and abuse score come from Cloudflare, IPinfo and AbuseIPDB.

Pipeline: Caddy + Anubis logs → Vector → Cloud Storage → BigQuery (hourly) → Looker Studio.
