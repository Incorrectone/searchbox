    💡 Why these resultsranking

    Every query runs two searches at once:

    S meaning: the 100 posts whose embedding is closest to your query's (MiniLM, pgvector HNSW).

    K keywords: the 100 best full-text matches (PostgreSQL tsvector).

    The two lists are merged with Reciprocal Rank Fusion: score = ∑ 1 / (60 + rank). Each result shows which list found it.

    ✦ About the AI summaryRAG

    Only runs when you click Summarize. The top 5 results are given to the model, which must answer only from them and cite them as [1]–[5].

    Answers are shown as plain text; only the [n] markers become links, and only to the results themselves, so text inside a crawled page can't inject links.
